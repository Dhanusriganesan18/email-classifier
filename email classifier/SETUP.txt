## 💡 USAGE EXAMPLES

### Example 1: Train and Evaluate
```bash
python src/spam_classifier.py
```

### Example 2: Make Predictions
```python
from src.spam_classifier import SpamClassifier

classifier = SpamClassifier.load_model('models/spam_classifier_model.pkl')

# Single prediction
pred = classifier.predict(["Hello, how are you?"])
# Output: [0] = Ham

# Get probability
proba = classifier.predict_proba(["Hello, how are you?"])
# Output: [[0.95 0.05]] = 95% ham, 5% spam
```

### Example 3: Batch Predictions
```python
messages = [
    "Hey, meeting at 3pm?",
    "BUY NOW!!! CLICK HERE!!!",
    "Thanks for your help"
]
predictions = classifier.predict(messages)
probabilities = classifier.predict_proba(messages)

for msg, pred, proba in zip(messages, predictions, probabilities):
    label = "SPAM" if pred == 1 else "HAM"
    print(f"{msg} -> {label} ({max(proba)*100:.1f}%)")
```
